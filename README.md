# Website Spesial 2nd Anniversary (08 November 2024 - Forever)

Website interaktif romantis estetis yang dibuat khusus untuk merayakan **2 Years Anniversary (2 Tahun Pacaran / Bersama)** pada **08 November**.

Berbasis **React + Vite + Tailwind CSS + Framer Motion**, dengan tema mewah **Romantic Velvet Wine & Rose Champagne Gold** yang sangat berbeda dari tema Blue Navy sebelumnya.

---

## ✨ Fitur & Rangkaian Kisah Cinta

1. **Floating Rose Petals & Embers Canvas:**
   - Animasi kelopak mawar berguguran dan partikel cahaya lembut melayang di layar.

2. **Cover Amplop 3D Wax Seal (Rose Gold & Crimson):**
   - Segel lilin mewah dengan logo hati berdenyut "Ketuk untuk Membuka".
   - Saat dibuka, tutup amplop berputar 180° secara 3D, surat cinta melayang keluar, partikel hati meletup, dan musik romantis otomatis mulai berputar.

3. **Sticky Navbar & Spotify-style Music Player:**
   - Pemutar piringan hitam (*vinyl disc*) yang berputar saat musik diputar.
   - Dilengkapi visualizer gelombang suara, tombol putar/jeda, serta tombol cepat untuk Kembang Api, Kuis Cinta, dan QR Code.

4. **The Day Our Story Began & Live Love Journey Counter:**
   - Menandai tanggal **08 November 2024** di kalender dengan cincin hati bercahaya emas.
   - **Penghitung Waktu Nyata (Live Real-time Counter):** Menghitung Hari (730+ Hari), Jam, Menit, dan Detik bersama yang terus berdetak setiap detik.
   - Statistik perjalanan: *17.520+ Jam*, *1.051.200+ Menit*, dan tombol interaktif *Kirim Denyut Cinta*.

5. **2nd Anniversary Cake & Celebration Toast:**
   - Kue perayaan 2 tingkat dengan 2 lilin bercahaya api realistis.
   - Ketuk untuk meniup lilin $\rightarrow$ lilin padam mengeluarkan asap lembut + letupan konfeti hati & emas yang meriah (*confetti blast*)!
   - Frame foto retro kamera berdua berjas almamater Polinema bertopi koboi.

6. **4 Hal yang Membuatku Selalu Jatuh Cinta (Reasons Why):**
   - Kartu-kartu interaktif yang dapat diklik untuk membuka alasan cinta yang tulus dan mendalam:
     1. Senyuman & Tawamu
     2. Kesabaran & Pengertianmu
     3. Momen Konyol Berdua
     4. Tumbuh & Berproses Bersama

7. **Scrapbook 730 Hari & Foto Polaroid Berdua:**
   - Menampilkan foto-foto asli hasil unduhan dari Google Drive dengan bingkai polaroid, washi tape, dan tulisan tangan manis.
   - Surat cinta pendek pop-up dari amplop saku mini.

8. **Surat Cinta Mendalam & Bingkai Cermin Klasik:**
   - Bingkai cermin oval klasik (*ornate mirror frame*) berisi foto bersandar manis berdua.
   - Surat cinta panjang 2nd anniversary yang menyentuh hati di atas kaca frosted elegan.

9. **Bulan Emas 3D & Galeri Foto Lightbox:**
   - Bulan 3D berputar lambat di bawah langit malam penuh bintang.
   - Galeri 8 foto photoshoot terbaik yang dapat diklik untuk memperbesar ke mode layar penuh (Lightbox) dengan navigasi panah kiri/kanan.

10. **Kuis Kenangan Cinta Kita (Love Quiz Modal):**
    - Kuis interaktif 4 pertanyaan manis seputar perjalanan cinta berdua, almamater, dan komitmen.
    - Selebrasi piala & konfeti saat kuis selesai.

11. **Generator Heart QR Code:**
    - Membuat QR code berbentuk hati yang bisa diunduh sebagai gambar PNG untuk dicetak di kartu ucapan fisik atau dibagikan ke WhatsApp.

## 🌐 Cara Deploy ke Vercel (Gratis)

1. Buat repository baru di GitHub dan upload folder ini:
   ```bash
   git init
   git add .
   git commit -m "Happy 2nd Anniversary Website"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPO_NAME.git
   git push -u origin main
   ```
2. Hubungkan repository ke [Vercel](https://vercel.com) $\rightarrow$ klik **Deploy**!
