# The 730 Days Love Studio & Memory Capsule (2nd Anniversary • 08 November)

Website interaktif romantis estetis yang dibuat khusus untuk merayakan **2 Years Anniversary (2 Tahun Bersama)** pada **08 November 2024 - 08 November 2026**.

Mengusung konsep studio cinta modern (**Bento Love Studio**, **Korean 4-Cut Photobooth Strip**, **Physical Draggable Polaroids**, **"Open When..." Memory Capsules**, **Typewriter Love Letter**, dan **Sky Lantern Finale**).

## ✨ Alur Pengalaman Baru (The Overhauled Concept)

1. ✈️ **Boarding Pass Flight LOVE-0811 (Tiket Masuk Interaktif):**
   - Tiket pesawat cinta mewah warna Rose Gold & Midnight Velvet.
   - Penumpang: *Yoga & Sayang*, Asal: *08 NOV 2024*, Tujuan: *FOREVER*.
   - Aksi sobek / validasi tiket dengan efek konfeti dan musik otomatis berputar.

2. ⏱️ **The 730 Days Bento Studio:**
   - **Live Love Clock:** Menghitung Hari (730+ Hari), Jam, Menit, dan Detik bersama secara real-time.
   - **Heart Rhythm:** Tombol kirim denyut cinta dengan getaran dan letupan partikel.
   - **Retro Cassette Tape Player:** Visual kaset pita berputar lembut saat melodi diputar.
   - **Milestone Badges:** 17.520+ Jam, 1.051.200+ Menit, 1000% Soulmate Match.

3. 📸 **Korean 4-Cut Photobooth Strip (Viral Style):**
   - Format 4 frame vertikal ala Photoism/Haruka dengan foto-foto photoshoot Polinema.
   - **Tombol 1-Klik Unduh Gambar PNG:** Menghasilkan strip gambar resolusi tinggi siap disimpan ke galeri HP atau dicetak.

4. 💌 **"Open When..." Secret Capsules (4 Amplop Rahasia):**
   - *Buka Saat Kamu Kangen Aku*
   - *Buka Saat Harimu Terasa Berat*
   - *Buka Saat Kamu Butuh Pengingat Komitmen Kita*
   - *Buka Khusus Hari Ini (08 November)*

5. 🖼️ **Meja Polaroid Interaktif (Physics Draggable Desk):**
   - Sensasi meja kenangan nyata: foto-foto polaroid berwashi-tape berserakan dan bisa digeser, dilempar, serta ditata bebas di layar menggunakan sentuhan jari.
   - Ketuk foto untuk memperbesar tampilan (Lightbox).

6. 📜 **Warkat Kasih Mesin Tik (Typewriter Letter):**
   - Surat cinta 2 tahun di atas kertas surat antik dengan segel lilin mawar dan tanda tangan digital.

7. 🏮 **Pelepasan Lentera Harapan (Sky Lantern Finale):**
   - Lentera 3D bercahaya api hangat. Ketik atau pilih doa untuk tahun ke-3, lalu terbangkan ke langit malam berbintang diiringi kembang api hati.

8. 🎁 **Fitur Ekstra:**
   - **Heart QR Code Generator:** Membuat QR code cinta untuk kartu ucapan fisik.
   - **Kuis Kenangan Kita:** Kuis interaktif 4 pertanyaan tentang perjalanan cinta berdua.
